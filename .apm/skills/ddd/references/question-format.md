# 問いかけ Markdown の書式

`ddd.mjs questions` が `documents/ddd/questions.md` に書く形。一時ファイルで、回答が済んだら消す（コミットしない）。

````markdown
# 探索セッションの問い

> これは一時ファイルです。/ddd が作り、回答が済んだら削除します。コミットしないでください。

テーマ: <explorer が示したテーマ>

<explorer の前置き>

## 確かめ方

選択肢ごとに「選ぶとどうなるか」をモデルで動かせます。

```bash
cd lean && lake build && node mockup/server.mjs   # → http://localhost:8787
```

画面の「シナリオ」から、下の表の「モックアップ」欄の名前を選んでください。表示されるのはモデルを実際に動かした結果です。
````

## 決めごと

- 選択肢に無い答えを書いてよい。「その他」は用意せず、回答欄は自由記述。
- 1 つの選択肢に主張を 2 つ束ねない（「A、かつ B」は分ける）。
- `回答:` の行より下、次の `## ` までが回答。空なら未回答。
- 質問は explorer が返した順・数のまま。数の上限は無い（往復のほうが高くつく）。
- 「選ぶとどうなるか」はモデルを動かして見せる。状態で表せるものは `Runtime/Scenarios.lean` の一時シナリオ、規則が変わるものは一時の枝。呼び名・画面の割り方など状態でも規則でもないものは用意しない。でっち上げない。
