# ローカル環境

本番同等の構成をコンテナで再現する。日々の開発ループ（Lean CLI 相手の画面・backend の単体起動）と同居できるようポートを分ける。

## 構成

| コンポーネント | 像 | ポート | 備考 |
|---|---|---|---|
| DB | | | 本番と同じメジャーバージョン |
| モック発行者（OIDC） | | | 人を選ぶだけでサインインできる。backend の経路（JWT + JWKS）は本番と同じ |
| backend | | | ホスト / CI で焼いた jar を包む |
| frontend（nginx） | | | `/api/*` を backend に振り same-origin を保つ |

## 立て方・片付け

## 時刻を固定する（E2E 用）

backend と発行者の両方の時計を同期して固定できるようにし、本番イメージには焼かない。

## コンテナの鮮度

作り直す前に Created と HEAD の時刻を突き合わせる。
