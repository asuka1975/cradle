# 本番環境

## 構成

| コンポーネント | サービス | 決定 |
|---|---|---|
| 入口 | | same-origin（`/api/*` を backend へ）。API 経路のエラー契約を前段が書き換えない |
| backend | | 複数タスク常駐。直列化点は DB |
| DB | | |
| 認証 | | トークンは backend が検証。立場はトークンに入れない |
| 秘密 | | state・ログ・リポジトリに載せない |
| 監視 | | 5xx 率・応答時間・稼働数・ログ由来エラー。通知先を空にしない |
