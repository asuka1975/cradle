# ai-notes — AI の申し送り

ここにあるのは AI が書いた申し送り・保留課題・検討メモと、**規約の候補**である。
**規約ではない。** ユーザーが承認したものだけが規約になる。昇格先は 2 つ:
このプロジェクト固有の決めごとは `documents/decisions.md`（表: 日付・決定・根拠・出典の ai-note）、
どのプロダクトにも効く汎用の規約は Cradle への提案（配られた rules を直接編集しない — 次の install で上書きされる）。
ドメインの事実の正本は `documents/ddd/`。

- ファイル名: `YYYYMMDD-NN-<topic>.md`。骨格は `TEMPLATE.md`（事実 → なぜ問題か → 判断が要ること（案の表）→ 選ばなかった対応 → 誰が決めるか）
- 冒頭に必ず次の断りを置く:

  > **これは規約ではありません。** AI が書いた申し送り・検討メモであり、**従うべきルールではない**。

- 「技術的に筋の良い選択肢が仕様と相反して採用できない」「設計判断を含むので勝手に決められない」
  課題は、黙って握らずここに書き置いてユーザーに判断させる。
- ai-notes の記述を根拠にコードを書いたり、規約として引用したりしない。
