# ユビキタス言語の種

ドメインエキスパートの語彙をそのまま収集した用語集。**コード上の命名はここの英語候補に従う**。

モデル（形式化役）が付けた名前（コマンド・失敗・画面の口）は、ここに行が立つまで `cradle unslop` の lean-name-unlisted が列挙し、探索セッションの開始時に `naming.md`（同じ置き場の一時ファイル）に写される。
エキスパートが確定した用語をここに行として立てる（用語 = エキスパートの言葉、英語候補 = 識別子。別の英語名を望めばそれを英語候補にする）。用語の行が既にあれば英語候補の空欄を埋める（行は増やさない）。

状態は「種」（発言から拾っただけ）/「確定」（定義をエキスパートが確認済み）の 2 段階。
英語候補はコード上の命名の候補。未定なら空欄でよい。
